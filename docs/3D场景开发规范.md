## 🎯 设计原则

### 核心目标
- **教育性**：让初中生都能动手学习并理解
- **交互性**：重要部件可点击，有即时反馈
- **沉浸感**：模拟真实世界的物理效果和原理
- **可读性**：场景清晰可见，UI不遮挡主体

### 设计准则

| 准则 | 说明 | ✅ 正确做法 | ❌ 错误做法 |
|------|------|------------|------------|
| **主体优先** | 3D内容是核心 | UI放边缘，可折叠 | UI覆盖在3D上方 |
| **渐进式引导** | 初始简单，逐步深入 | 先展示整体，点击查看细节 | 一次展示所有信息 |
| **即时反馈** | 交互有明确响应 | 点击高亮+弹框说明 | 点击无反应 |
| **物理真实** | 动画符合物理规律 | 活塞符合曲轴运动 | 随机运动 |

## 🖱️ 交互设计规范

### 1. 点击交互

每个可点击对象必须配置 `userData`：

```javascript
const mesh = new THREE.Mesh(geometry, material);

// 交互配置
mesh.userData = {
    name: '部件名称',           // 显示名称
    description: '详细说明',    // 弹框内容
    onClick: (target) => {      // 点击回调
        this.showInfo(target);
    }
};

// 加入可交互列表
this.interactables.push(mesh);
```

### 2. 信息弹框规范

使用侧边信息面板，不遮挡主体：

```javascript
showInfo(target) {
    const panel = document.getElementById('info-panel');
    const title = document.getElementById('info-title');
    const content = document.getElementById('info-content');
    
    title.innerText = target.userData.name;
    content.innerHTML = `
        <div class="text-gray-300 mb-4">
            ${target.userData.description}
        </div>
        <!-- 可添加更多交互控件 -->
    `;
    
    panel.classList.add('visible');
}
```

### 3. 控制按钮规范

底部控制栏用于场景特殊操作：

```javascript
setupControls() {
    const controlsDiv = document.getElementById('scene-controls');

        <button class="control-btn" id="btn-xxx">
            <i class="fas fa-xxx"></i> 按钮文字
        </button>
    `;
    
    document.getElementById('btn-xxx').onclick = () => {
        // 处理逻辑
    };
}
```

## 📝 新增案例流程

### 第一步：创建场景文件

复制模板 `scenes/templates/scene-template.js` 到 `scenes/` 目录：

```bash
# 例如创建"电路原理"场景
cp scenes/templates/scene-template.js scenes/circuit-scene.js
```

### 第二步：实现场景逻辑

按照模板结构实现：
- `init()` - 创建3D对象
- `animate()` - 动画逻辑
- `getInteractables()` - 返回可点击对象
- `createLabels()` - 创建文字标签

### 第三步：注册案例配置

编辑 `data/cases-config.js`，在 `CASES` 数组中添加：

```javascript
{
    id: 'circuit',
    title: '电路原理',
    keywords: ['电路', '电流', '电压', '欧姆'],
    type: 'scene',
    sceneClass: 'CircuitScene',
    icon: 'fa-bolt',
    description: '欧姆定律可视化，理解电流电压关系',
    difficulty: 2
}
```

### 第四步：添加代码片段

编辑 `data/code-snippets.js`，添加对应代码：

```javascript
circuit: `function initCircuit() {
    // 电路模拟代码...
}`
```

### 第五步：引入脚本

在 `index.html` 中添加场景脚本：

```html
<script src="scenes/circuit-scene.js"></script>
```

### 第六步：测试验证

1. 启动本地服务器
2. 输入关键词测试匹配
3. 验证3D交互效果
4. 检查信息面板显示
