## 🎯 规范定位与适用范围

### 本规范与3D场景开发规范的区别

| 对比维度           | 3D场景开发规范              | 题目可视化规范（本文档）       |
| ------------------ | --------------------------- | ------------------------------ |
| **核心目的** | 原理/概念/现象的可视化理解  | 帮助学生学习解题方法           |
| **内容重点** | 动态演示、探索发现          | 解题步骤、思路讲解             |
| **教学形式** | 自由探索、参数调节          | 黑板式教学、分步引导           |
| **典型场景** | 电磁感应、DNA结构、行星运动 | 几何证明、力学计算、化学方程式 |
| **交互目标** | 理解"为什么"                | 掌握"怎么做"                   |
| **视觉风格** | 深色Blender风格             | 纯白/浅色教室风格              |

### 适用场景判断

当用户提出3D场景需求时，**必须先判断场景类型**：

```
用户需求
    ↓
是否包含明确的"题目"或"求解"要求？
    ↓
    ├─ 是 → 使用【题目可视化规范】
    │        ├─ 有具体题目条件
    │        ├─ 需要求解/证明/计算
    │        ├─ 需要展示解题步骤
    │        └─ 需要黑板式教学面板
    │
    └─ 否 → 使用【3D场景开发规范】
             ├─ 展示原理/现象
             ├─ 概念可视化
             ├─ 自由探索为主
             └─ 无明确解题要求
```

### 需求确认话术

```
【题目场景识别】
检测到您的需求包含明确的题目解答要求，我将采用【题目可视化规范】进行开发。

该规范特点：
✅ 纯白/浅色背景，模拟教室环境

请确认是否按此规范开发？
```

## 🧠 核心设计理念

### 设计哲学：让解题变成"看得见"的过程

```
传统解题：读题 → 思考 → 列式 → 计算 → 答案
可视化解题：看题 → 动手操作 → 观察规律 → 理解原理 → 掌握方法
```

### 教学体验金字塔

```
                    ┌─────────────────────┐
                    │  5. 举一反三        │  ← 变化条件，验证方法
                   ┌┴─────────────────────┴┐
                   │  4. 掌握方法          │  ← 总结解题技巧
                  ┌┴───────────────────────┴┐
                  │  3. 理解原理            │  ← 为什么这样做？
                 ┌┴─────────────────────────┴┐
                 │  2. 观察过程              │  ← 动态演示解题步骤
                ┌┴───────────────────────────┴┐
                │  1. 读懂题目               │  ← 可视化题目条件
                └──────────────────────────────┘
```

### 五大必须原则

| 原则               | 要求               | 实现方式                     |
| ------------------ | ------------------ | ---------------------------- |
| **正确性**   | 解题过程100%正确   | 公式推导、计算步骤都要验证   |
| **可操作性** | 学生能动手参与     | 拖拽图形、调整参数、触发步骤 |
| **分步引导** | 步骤清晰，循序渐进 | 6步左右的解题流程            |
| **详细讲解** | 每步都有原因说明   | 黑板面板包含完整讲解         |
| **即时反馈** | 操作后立即看到结果 | 图形变化、数值更新、动画效果 |

题目可视化场景采用**纯白/浅色背景**，模拟教室黑板/白纸环境：

## 🏗️ 场景结构设计

### 标准类结构

```javascript
window.XxxProblemScene = class XxxProblemScene {
    constructor(scene, camera, renderer) {
        // ========== 核心属性 ==========
        this.scene = scene;
        this.camera = camera;
        this.renderer = renderer;
      
        this.mainGroup = null;
        this.interactables = [];
        this.highlighted = null;
      
        // ========== 题目数据 ==========
        this.problemData = {
            title: '题目标题',
            conditions: [],       // 已知条件
            question: '',         // 求解目标
            knowledgePoints: [],  // 涉及知识点
            difficulty: 3         // 难度 1-5
        };
      
        // ========== 几何/图形元素 ==========
        this.points = {};         // 所有点
        this.lines = {};          // 所有线
        this.shapes = {};         // 所有图形
        this.labels = {};         // 所有标签
        this.auxiliaryElements = []; // 辅助元素
      
        // ========== 解题步骤 ==========
        this.solutionSteps = [
            { id: 0, title: '📖 读题', action: 'readProblem' },
            { id: 1, title: '🔄 动态演示', action: 'demonstrate' },
            { id: 2, title: '❓ 发现规律', action: 'discover' },
            { id: 3, title: '✏️ 构造辅助', action: 'construct' },
            { id: 4, title: '📐 推导计算', action: 'calculate' },
            { id: 5, title: '✅ 得出结论', action: 'conclude' }
        ];
        this.currentStep = 0;
        this.maxStep = 5;
      
        // ========== 状态管理 ==========
        this.isAutoPlaying = false;
        this.isDragging = false;
        this.showAuxiliary = false;
      
        // ========== 相机配置 ==========
        this.defaultCameraPos = { x: 0, y: 0, z: 20 };
      
        // ========== 颜色方案 ==========
        this.colors = MATH_COLORS; // 或 PHYSICS_COLORS 等
    }

    // ========== 生命周期方法 ==========
    init() {
        this.setupBackground();
        this.setupLights();
        this.setupEnvironment();
        this.setupScene();
        this.setupUI();
        this.setupDragControl();
        this.createInfoPanel();
      
        setTimeout(() => {
            this.showGuide('📝 拖动图形或点击"解题步骤"开始学习');
        }, 500);
    }
  
    animate(time, delta) {
        // 自动演示逻辑
        if (this.isAutoPlaying) {
            this.updateAnimation(time);
        }
      
        // 控制点呼吸效果
        this.updateControlPoints(time);
    }
  
    getInteractables() {
        return this.interactables;
    }
  
    dispose() {
        this.cleanupUI();
        if (this.mainGroup) this.scene.remove(this.mainGroup);
    }
  
    onBackgroundClick() {
        this.hideInfoPanel();
        this.clearHighlight();
    }
  
    // ========== 必须实现的方法 ==========
    setupScene() { /* 创建题目图形 */ }
    setupUI() { /* 创建控制按钮 */ }
    setupDragControl() { /* 实现拖拽交互 */ }
    showStepGuide() { /* 显示黑板面板 */ }
    executeStepAction(action) { /* 执行步骤动作 */ }
    reset() { /* 重置场景 */ }
    resetView() { /* 重置视角 */ }
};
```

## 📚 黑板式教学面板

### 面板结构

黑板面板是题目可视化的核心教学组件，必须包含以下内容：

> ⚠️ **强制要求**：所有面板、模态框、弹窗都**必须有关闭按钮**（×），且在PC端和移动端都要**清晰可见、可点击**。关闭按钮触摸区域在移动端不小于 44×44px。

```
┌─────────────────────────────────────┐
│  📋 题目名称                    [×] │ ← 标题栏（关闭按钮必须有）
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐    │
│  │ 📋 原题                      │    │ ← 题目区
│  │ 题目条件和求解目标...        │    │
│  └─────────────────────────────┘    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │ 💡 知识点                    │    │ ← 知识点
│  │ [标签1] [标签2] [标签3]      │    │
│  └─────────────────────────────┘    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │ 🧠 解题思路                  │    │ ← 思路区
│  │ ❓ 直觉想法                  │    │
│  │ 💡 发现问题                  │    │

│  ┌─────────────────────────────┐    │

                            <span class="step-number">${i + 1}</span>

                <div class="current-step-detail">

                        <span class="step-title-text">${step.title}</span>
                    </div>
                    <div class="step-detail-content">
                        ${detailedContent}
                    </div>
                </div>
            </div>
        </div>
      
        <div class="blackboard-footer">
            <button class="bb-btn bb-btn-secondary" id="bb-prev" ${this.currentStep === 0 ? 'disabled' : ''}>
                <i class="fas fa-arrow-left"></i> 上一步
            </button>
            <button class="bb-btn bb-btn-primary" id="bb-action">
                <i class="fas fa-play"></i> 演示
            </button>
            <button class="bb-btn bb-btn-secondary" id="bb-next" ${this.currentStep >= this.maxStep ? 'disabled' : ''}>
                下一步 <i class="fas fa-arrow-right"></i>
            </button>
        </div>
    `;
}
```

```javascript
setupDragControl() {
    const container = document.getElementById('scene-canvas-container');
    const raycaster = new THREE.Raycaster();
    const mouse = new THREE.Vector2();
  
    const onMouseDown = (event) => {
        // 射线检测
        raycaster.setFromCamera(mouse, this.camera);
        const intersects = raycaster.intersectObjects(this.dragablePoints);
      
        if (intersects.length > 0) {
            this.dragTarget = intersects[0].object;
            this.isDragging = true;
          
            // 🔑 关键：禁用OrbitControls
            if (window.sceneManager?.controls) {
                window.sceneManager.controls.enabled = false;
            }
          
            event.stopPropagation();
            event.preventDefault();
        }
    };
  
    const onMouseMove = (event) => {
        if (!this.isDragging) return;
      
        // 更新鼠标位置
        // 计算拖拽目标的新位置
        // 约束在有效范围内（如圆上、线段上）
        this.updateDragPosition(event);
      
        // 更新图形
        this.updateGeometry();
      
        event.stopPropagation();
    };
  
    const onMouseUp = () => {
        if (this.isDragging) {
            // 恢复OrbitControls
            if (window.sceneManager?.controls) {
                window.sceneManager.controls.enabled = true;
            }
        }
        this.isDragging = false;
        this.dragTarget = null;
    };
  
    // 使用捕获阶段
    container.addEventListener('mousedown', onMouseDown, true);
    container.addEventListener('mousemove', onMouseMove, true);
    container.addEventListener('mouseup', onMouseUp, true);
}
```

## 📖 学科专项指南

### 数学几何题

**特点：**

- 纯白背景，模拟纸张
- 2D几何居多，可在XY平面展示
- 需要辅助线功能
- 强调构造方法和证明过程

**必备元素：**

- 点、线、圆、多边形
- 标签（点名、长度、角度）
- 辅助线（虚线、绿色）
- 面积着色（半透明）

### 立体几何题

**特点：**

- 纯白背景
- 真正的3D场景，需要旋转观察
- 截面问题常见
- 强调空间想象力

**必备元素：**

- 正方体/棱柱/棱锥等
- 顶点标签（A、B、C...）
- 截面（红色半透明）
- 控制点（绿色可拖拽）

**特点：**

- 浅色背景
- 力的箭头是核心
- 需要分解力
- 强调平衡条件

**必备元素：**

- 物体（方块、球体）
- 力箭头（带标签）
- 坐标系
- 角度标注

### 化学分子结构

**特点：**

- 白色背景
- 球棍模型
- 原子颜色有约定
- 强调空间构型

**必备元素：**

- 原子球（颜色约定）
- 化学键（单/双/三键）
- 键角标注
- 分子式显示
